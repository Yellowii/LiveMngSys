直播弹幕上车规则速查

一、队列
1. 上车：进入基础区队尾，自带2局。
2. 超车：进入置顶区，排在基础区前面。
3. 同一用户可同时在置顶区和基础区；轮到时先按置顶区处理。
4. 每次超车都是一个独立批次，按指令接受时间排队；同一用户后续超车只能追加到队尾。
5. 例如：A超车2 → B超车2 → A再次超车，执行顺序为 A → B → A。
6. 加班队列单独维护，显示在主队列后方，不参与基础区和置顶区排序。
7. 每人单场累计最多加班6局，已完成和排队中的局数都计入上限。

二、局数上限
1. 已在基础区：最多6局。
2. 不在基础区：最多4局。
3. 已在基础区且超车超过4局时，基础2局转入置顶，基础位置移除，最终6局。
4. 不在基础区发送“超车6局”，自动按“超车4局”处理。

三、弹幕指令
上车
- 加入基础区队尾，基础2局。
- 回复：您已上车，当前排队第X位

超车2局
- 场次OPEN且贡献余额足够即可使用，不受上车功能开关影响。
- 会员：扣299贡献；非会员正常路径扣398贡献。
- 非会员已有基础车位且余额>=398：扣398，新增超车车位，基础车位保留。
- 非会员已有基础车位且余额299~397：扣299，将最前基础车位移入超车队列。
- 非会员没有基础车位：余额>=398，扣398后直接进入超车队列，不创建基础车位。
- 非会员已有基础车位且余额500发送超车2局：扣398，基础车位保留，余额剩102。
- 无基础车位最高4局；超车6局按超车4局处理。
- 置顶增加2局。
- 已在基础区且累计不超过4局：基础保留。
- 已在基础区且累计超过4局：转为6局，基础移除。

超车4局
- 有权限才可用。
- 置顶增加到4局。
- 已在基础区且触发超过4局：转为6局，基础移除。

超车6局
- 有权限才可用。
- 已在基础区：直接转为6局，基础移除。
- 不在基础区：自动降级为4局。

预约HH:MM
- 示例：预约22:00
- 只加预约标签，不改变队列顺序。
- 原规则为预约时间前后20分钟提醒窗口。

换位6
- 发起者必须在基础区，且基础区排名小于6。
- 向基础区第6位发送申请。
- 对方30秒内发送“同意换位”后，双方基础位置互换。
- 只换基础区位置，不影响超车。

延迟上车
- 添加延迟标记。
- 轮到时自动跳过，位置和局数不变。
- 发送“准备上车”恢复。

准备上车
- 取消延迟标记。
- 下次轮到即可正常上车。

取消上车
- 清除置顶区、基础区、预约、延迟。
- 不清除加班队列。
- 回复：您已退出主队列

查询车位
- 置顶优先返回。
- 前端定位并高亮10秒。
- 同一用户多次超车：显示多个批次位置，不得把后续超车合并回第一次位置。

转移N局 @用户
- 转出方是发送者，接收方是@用户。
- 按转出方车位的实际执行顺序，从前往后标记。
- 当前车位不够时，继续检查该用户后续车位。
- 不改变原用户、车位位置和队列顺序，只增加“转给@用户N局”标记。
- 不足请求数量时，全部标记并提示实际转移数量。
- 已标记局数不可重复转移，接收方不新增车位。

加班N局
- 已获得加班权限后才能发送。
- 加入独立加班队列队尾，按发送时间排序。
- 单场累计最多6局；超过剩余额度时整条指令拒绝，不自动截断。
- 不改变基础区和置顶区，不占用主队列车位。
- 重复发送生成独立加班批次。

取消加班
- 清除自己的加班批次。
- 不影响基础区、置顶区和转移标记。

四、常用回复
上车成功：您已上车，当前排队第X位
首次超车2局：已置顶（2局）
首次超车4局：已置顶（4局），基础排队保留
叠加至4局：已叠加至4局，基础排队保留
转移至6局：已叠加至6局，基础额度已转移，原基础位置已移除
超车6局但不在基础区：您不在基础队列中，自动转为超车4局
已达上限：您已满X局上限，无法继续叠加
预约成功：已预约HH:MM，将提前提醒您
换位申请：已向第6位用户发送换位申请，等待对方回复
换位成功：换位成功！您当前在基础区第X位
换位超时：换位请求已超时
延迟成功：已标记延迟，轮到您时将自动顺延；发送“准备上车”恢复
准备上车：已取消延迟，排队状态恢复正常
取消上车：您已退出主队列
未排队查询：您尚未上车
转移成功：已将您的X局车位标记为转给@用户B，队列位置保持不变
转移不足：您可转移的车位只有X局，已全部标记给@用户B，仍有Y局未满足
无加班权限：暂无加班权限
加班成功：已加入加班队列，当前加班排队第X位
加班超限：本场您还可加班X局，请重新发送“加班X局”
取消加班：您已退出加班队列

五、权限
上车：不需要用户权限，但必须已开播且上车功能已开启。
超车2局、超车4局、超车6局：场次OPEN且贡献满足即可，不检查上车功能开关。
超车每2局：会员扣299贡献；非会员正常路径扣398贡献；已有基础车位且余额299~397时，超车2局可降级扣299并转移基础车位。
加班N局：按身份和贡献余额计算，会员每2局299，非会员每2局398。
权限按每次接受指令时的快照校验。
超车贡献不足：暂不满足超车权限，当前还需要X贡献。
加班贡献不足：暂不满足加班权限，当前还需要X贡献。

六、后端维护速查
1. 读取到“开播”：创建新sessionId，重置上一场运行态，开启上车功能；历史日志不删除。
2. 读取到“关播”：先关闭上车功能，再保存基础上车列表、最终快照和本场全部弹幕/操作日志。
3. 重复开播或关播只记录事件，不重复重置、归档或扣额度。
4. 当前争议读取实时基础列表；下播复盘按sessionId读取最终快照和完整日志。
5. 每场保留基础队列、原始弹幕、解析结果、队列变化、权限变化和异常记录。
6. 开关播只重置本场运行态和本场额度，不删除长期超车或加班权限。
