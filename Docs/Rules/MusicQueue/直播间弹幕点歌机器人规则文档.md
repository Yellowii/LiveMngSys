# 直播间弹幕点歌机器人规则文档

版本：V1.0

---

# 一、积分 / 弹幕规则

## 1. 积分获取规则

| 获取方式  | 积分奖励        | 规则说明                   |
| ----- | ----------- | ---------------------- |
| 礼物贡献  | 1钻 = 1积分    | 每赠送1钻石礼物获得1积分          |
| 点赞奖励  | 500点赞 = 5积分 | 按本场直播累计点赞计算，尾数不足500不计入 |
| 直播打卡  | 10积分/次      | 每场直播可打卡1次              |
| 点亮灯牌  | 10积分/次      | 与礼物贡献积分可重复计算           |
| 会员用户  | 无限点歌权限      | 会员有效期内享受无限点歌           |
| 星守护用户 | 无限点歌权限      | 星守护有效期内享受无限点歌          |

---

## 2. 积分说明

* 积分用于直播间点歌、切歌、顶歌等互动功能。
* 系统自动记录用户积分变化。
* 用户可以发送：

```
查询余额
```

查看当前积分。

显示内容：

```
用户昵称
当前积分
可用权限
```

显示时间：

```
5秒
```

---

# 二、点歌设置

## 1. 点歌权限设置

支持以下模式：

### 免费点歌

所有用户均可免费点歌。

---

### 权限限制点歌

可选择：

| 设置       | 说明         |
| -------- | ---------- |
| 仅允许管理点歌  | 只有管理员可以点歌  |
| 管理免费点歌   | 管理员免费点歌    |
| 仅允许粉丝团点歌 | 仅粉丝团用户可以点歌 |
| 粉丝团免费点歌  | 粉丝团用户免费点歌  |
| 会员免费点歌   | 会员用户免费点歌   |
| 星守护免费点歌  | 星守护用户免费点歌  |

---

### 积分点歌

开启后：

```
消耗 XX 积分 / 首歌曲
```

普通用户点歌时自动扣除对应积分。

---

# 2. 点歌命令

## 歌曲名称点歌

格式：

```
点歌 + 歌曲名称
```

示例：

```
点歌 晴天
```

---

## 歌曲ID点歌

格式：

```
点歌 + 歌曲ID
```

示例：

```
点歌 186016
```

---

## 智能匹配

支持：

* 智能识别歌曲名称
* 自动去除空格
* 自动去除标点符号
* 模糊匹配歌曲
* 支持歌手+歌曲组合搜索

示例：

用户输入：

```
点歌 周杰伦-晴天!!
```

自动匹配：

```
周杰伦 晴天
```

---

# 3. 点歌冷却设置

## 用户点歌冷却

同一用户连续点歌：

```
XX秒内禁止重复点歌
```

示例：

```
60秒冷却时间
```

---

## 单曲播放限制

每首歌曲最大播放时间：

```
XX秒
```

超过时间后：

```
自动切歌
```

---

# 4. 点歌限制

## 查询余额

用户发送：

```
查询余额
```

系统显示：

```
@用户
当前积分：XXX
```

持续：

```
5秒
```

---

## 空闲歌单限制

可开启：

```
仅允许点播空闲歌单歌曲
```

开启后：
仅允许点播空闲歌单内的歌曲

---

## 点歌数量限制

设置：

```
播放列表最大歌曲数量：XX首
```

达到限制后：

提示：

```
当前点歌列表已满，请稍后再点歌
```

---

| 设置      | 说明       |
| ------- | -------- |

| 管理免费切歌  | 管理员免费切歌  |
| 会员免费切歌  | 会员免费切歌   |
| 星守护免费切歌 | 星守护免费切歌  |

```

```

# 五、超级置顶

## 功能说明

超级置顶为最高优先级歌曲。

特点：

* 无视普通播放队列
* 无视普通顶歌
* 优先播放

---

## 权限设置

支持：

* 管理员专属
* 会员权限
* 星守护权限
* 积分兑换

---

## 命令

格式：

```
超级置顶 + 歌曲名称
```

示例：

```
超级置顶 七里香
```

执行：

```
当前歌曲结束后立即播放
```

# 六、后台全局控制

## 1. 控制方式

支持接入：

* 快捷键
* WebSocket / WSS
* Stream Deck
* 宏键盘
* 妙联宝
* OBS WebSocket
* 自定义控制面板

---

# 2. 控制功能

## 点歌控制

| 功能   | 说明       |
| ---- | -------- |
| 开启点歌 | 开启弹幕点歌功能 |
| 关闭点歌 | 暂停用户点歌   |

---

## 播放控制

| 功能  | 说明       |
| --- | -------- |
| 播放  | 继续播放歌曲   |
| 暂停  | 暂停当前歌曲   |
| 上一首 | 播放上一首歌曲  |
| 下一首 | 播放下一首歌曲  |
| 切歌  | 立即结束当前歌曲 |

---

## 音量控制

支持：

```
音量+
音量-
```

可设置调整幅度：

```
±1dB
±5%
```

---

## 歌曲管理

### 拉黑歌曲

功能：

```
加入歌曲黑名单
```

效果：

* 禁止再次点播
* 搜索结果自动过滤

---

## 缓存路径设置

设置：

```
音乐缓存目录
```

示例：

```
D:\MusicBot\Cache
```

目录结构：

```
Cache

├── Music
│   └── mp3音频文件
│
├── Lyric
│   └── lrc歌词文件
│
├── Cover
│   └── 封面图片
│
└── Data
    └── 歌曲数据库
```
