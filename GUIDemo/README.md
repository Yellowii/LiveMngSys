# LiveMngSys GUI

该页面是 LiveMngSys 的主控制台，由根目录统一服务托管，不使用 Nuxt 或其他构建框架。

## 📁 目录与层级映射 (对照 Docs\GUI\html 规范)

本原型设计完全根据以下文件规范映射编写：
- **`Docs\GUI\基础框架.txt`**：规划了所有侧边栏一级类目及顶栏二级联动的菜单结构；
- **`Docs\GUI\html\Index.html`**：提取了关键的层级与分部容器，如：
  - **`#4_27`**：顶栏区域；
  - **`#4_33`**：状态栏对齐区域；
  - **`#4_29`**：主程序状态项；
  - **`#4_28`**：直播间连接状态项；
  - **`#4_30`**：系统通知弹出项；
  - **`#2_5` / `#4_3` / `#4_9` / `#4_21` / `#4_15`**：侧边栏中各大类的功能容器；
  - 侧边栏子项如 **`#2_8`** (运行状态)、**`#2_7`** (参数配置)、**`#4_5`** (实时弹幕) 等，均已严格使用相同的 DOM ID 和树状层级实现了 Vue 动态绑定。

## 使用

从项目根目录运行 `Start-LiveMngSys.cmd`，然后访问：

```text
http://<LAN-IP>:7000/GUIDemo/
```

页面资源、MusicBot 点歌界面和 WebSocket 均通过统一的 7000 端口提供。不要直接双击 HTML 文件，否则无法使用跨页面服务和实时接口。
